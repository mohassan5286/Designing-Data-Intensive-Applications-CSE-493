# Service discrption

This is a simple service that allows you to find out top 10 movies
depending on ratings.

# Steps to run the service on intellij

1. Clone the repository
2. Open the project in intellij
3. add dependencies, extension and plugins in the pom.xml file (based on this [docs](https://github.com/grpc/grpc-java/blob/master/README.md))
4. comiple protobuf files - use complie-custom & compile (both)
   ![img.png](img.png)
5. add generated files to the project structure
   ![img_1.png](img_1.png)
6. run the service using the normal run button
